# Mejoras UI v2

Esta versión refina la interfaz para uso interno por una persona adulta:

- Botones grandes y claros.
- Tipografía más legible.
- Contraste mejorado.
- Sidebar más profesional.
- Tarjetas con mejor jerarquía visual.
- Formularios más cómodos.
- Tablas con encabezado fijo.
- Estados visuales para deuda/pagado.
- Responsive para notebook y móvil.
- Modo impresión más limpio para vouchers/listados.
